# 古书阅读

移动端优先的古书对照阅读网页：原文与译文逐段对照，每段附地名解析，点地名弹出本段地图（古地名 → 今天的位置）。纯静态站点，可直接用 GitHub Pages 托管。

## 在线访问

开启 GitHub Pages（Settings → Pages → Branch 选 `main`、目录选 `/ (root)`）后，访问：

https://jackeeeeee.github.io/guji/

## 内容

- 书架两部书：《后汉书》120 卷、《三国志》65 卷完整目录，可搜索、按分类筛选、点开看单卷详情。
- 已内置原文与逐段译文、可直接读的卷：《后汉书》卷一（光武帝纪）、卷廿四（马援）、卷廿六（伏侯宋蔡冯赵牟韦列传，23 段全文）、卷五四（杨震）、卷五九（张衡），以及《三国志》武帝纪、先主传、诸葛亮传、吴主传、周瑜鲁肃吕蒙传的开头部分；其余卷为目录，粘贴原文后可调用自己的 API 翻译。
- 内置古地名库：点原文/译文里的地名、每段下面的「本段地名解析」或「本段地图」，弹出只属于该段的地图；另有全文地名总览与全文地图。

## 本机持久化（v2.0 起）

数据保存在浏览器本机的 IndexedDB 数据库 `gushu-reader` 中，关掉、刷新、重开页面都还在：

- **译文缓存**：自己翻译过的篇目自动落盘，下次打开同一卷直接读缓存，不再重复请求 API；缓存面板仍可导出成 JSON 文件备份、导入恢复。
- **上次浏览位置**：读到哪一卷、哪一段、段内比例与已读卷列表自动恢复（另在 localStorage 留一份同步镜像，并兼容旧版本记录的迁移）。
- **API 设置**：服务商、地址、模型与 Key 保存在本机浏览器，下次打开自动恢复。
- **阅读偏好**：纸面主题（纸黄 / 护眼绿 / 夜间）、行距、字号、显示模式与当前书自动恢复。

注意：本机持久化只在同一设备、同一浏览器内有效，清浏览器数据会丢失，不跨设备同步。

## 翻译 API

右上角齿轮打开设置，预设 DeepSeek、OpenAI、通义千问、Kimi、智谱，也可自定义任何兼容 OpenAI 接口格式的地址、模型与 Key。**Key 只在打开页面后由使用者在浏览器里填写并保存在本机，切勿写进仓库文件。** 未配置 Key 时为演示模式：内置篇目可正常阅读，粘贴的新篇目只标注地名、不生成译文。

## 工程结构

```
index.html            页面结构、样式与全部业务逻辑（经典脚本，无构建步骤）
assets/
  hatch-maps.css      地图组件样式
  hatch-maps.js       地图组件（Leaflet 打包）
  map_helpers.js      地图辅助函数
```

`index.html` 内部分层：数据层（地名库 / 两书目录 / 内置篇目，纯数据）→ 持久层（`Store`：IndexedDB 统一存取）→ 业务层（书架 / 翻译 / 对照阅读 / 分段地图）；启动流程为 `DOMContentLoaded → hydrate()` 恢复本机数据 `→ init()` 绑定与首屏渲染。地图瓦片、字体走 CDN，页面本身无后端、无构建。
